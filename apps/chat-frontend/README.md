# Session Chat Frontend

Angular 20 frontend for Session Chat. The UI uses Nebular components with Tailwind utility classes for layout and spacing.

## Development

From the repo root:

```bash
cd apps/chat-frontend
rushx start:dev
```

The dev server runs on `http://localhost:4200/`.

## Build

```bash
cd apps/chat-frontend
rushx build
```

## Test

```bash
cd apps/chat-frontend
rushx test
```

Browser tests use Karma. Legacy Protractor e2e scaffolding has been removed.
